1) COUNT, SUM, AVG
            - Data ka summary nikalna
            - "Kitne records fail hue?" "Total amount match kar raha hai?" — ye sawaal roz aate hain

2) GROUP BY + HAVING
            - Category wise summary
            - Har system ke liye alag error count — troubleshooting mein kaam aata hai

3) DISTINCT
            - Duplicate records dhundna
            - Duplicate data integration ka common problem hai — DISTINCT se turant dikh jaata hai

4) CREATE / ALTER TABLE
            - Temp table banana ya structure dekhna
            - Testing ke liye staging table banana — support mein ye bhi hota hai

5) DESC / SHOW TABLES
            - Table ka structure samajhna
            - Naye system mein jaao toh pehle structure samjho — ye shortcut hai
